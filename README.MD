## Sobre mim

Sou estudante de Engenharia de Software e desenvolvedor com foco em **backend, APIs bem estruturadas e sistemas escalaveis**. Minha base principal hoje esta em **Python, FastAPI, Django, Java e Docker**, e tenho expandido cada vez mais para o lado **full stack** com **Next.js, React e TypeScript**.

Gosto de construir produtos que nao ficam so bonitos no README: busco arquitetura clara, regras de negocio bem modeladas, integracoes solidas e codigo que continue sustentavel quando o projeto cresce.

- Foco atual em **APIs REST**, **mensageria**, **bancos relacionais e NoSQL** e **arquitetura orientada a eventos**
- Interesse forte em **design de sistemas**, **modelagem de dominio** e **performance**
- Experiencia recente com projetos de **SaaS**, **e-commerce**, **dashboards**, **apps mobile** e **plataformas web**

## Projetos em destaque

### [SCALE](https://github.com/BeiruthDEV/SCALE)
App dark theme para treino e nutricao, criado como projeto de TCC. A proposta combina acompanhamento de progresso, experiencia visual forte e organizacao de produto pensando em uso real.

`JavaScript` `Produto digital` `Treino` `Nutricao` `TCC`

### [ecommerce-design](https://github.com/BeiruthDEV/ecommerce-design)
Aplicacao full stack de e-commerce usada para demonstrar **Padroes de Projeto** em um fluxo completo de checkout, pagamento e gestao de pedidos.

`TypeScript` `Full Stack` `E-commerce` `Design Patterns`

### [Orbia](https://github.com/BeiruthDEV/Orbia)
Sistema web em Django para gestao de empresas, representantes, projetos e pesquisas, com autenticacao e controle de permissao por tipo de usuario.

`Django` `Python` `Sistema web` `Autenticacao`

### [gestao-ativa-demo](https://github.com/BeiruthDEV/gestao-ativa-demo)
SaaS de financas pessoais com dashboard, categorizacao automatica de transacoes, parsing de PDF/CSV e deteccao de recorrencias.

`Next.js` `FastAPI` `Python` `SaaS` `Financas`

### [loveline-demo](https://github.com/BeiruthDEV/loveline-demo)
SaaS para casais registrarem a historia do relacionamento em uma timeline compartilhada, com proposta de produto voltada para experiencia, memoria e recorrencia de uso.

`SaaS` `Produto digital` `Timeline` `Experiencia do usuario`

### [transflow-backend](https://github.com/BeiruthDEV/transflow-backend)
Backend orientado a eventos para gestao de corridas urbanas, com foco em escalabilidade, processamento assincrono e arquitetura de microsservicos.

`FastAPI` `RabbitMQ` `Redis` `MongoDB` `Docker`

### [glass-weather-app](https://github.com/BeiruthDEV/glass-weather-app)
Aplicacao React Native consumindo a Open-Meteo API para exibir dados climaticos em tempo real com uma interface moderna e responsiva.

`React Native` `TypeScript` `API Integration` `Mobile`
